# paloma

A Rust UI framework for command-line programs that run one action and exit: prompts, flows of prompts, messages, loading messages and progress bars, styled by one app-wide theme and configured by app-wide options. Everything works out of the box with sensible defaults and minimal code, and every look and behaviour can be changed from there with paloma's own tools. Anything but full-screen GUIs.

The prompts are built (confirm, text and password input, select, multi-select, sort, fuzzy search); the other components are being built now, see the [roadmap](ROADMAP.md).

paloma is a fork of [dialoguer](https://github.com/console-rs/dialoguer) (MIT) and builds on [console](https://github.com/console-rs/console).
